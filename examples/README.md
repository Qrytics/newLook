# Examples

Two real design systems saved after running the workflow. Read them to see the expected shape of a good result: a direction in words, named tokens, a signature element, and what the audit caught.

| File | Project | What it shows |
|---|---|---|
| `metaflow/system.md` | A React + TypeScript + Vite dashboard (a standup-to-PR tool) | Warm paper, one vermilion correction mark, a five-stage pipeline strip as the signature |
| `metabridge/system.md` | A vanilla-JS canvas app (one keyboard and mouse across two computers) | A light "bench" holding two dark screens, a 0 to 1920 ruler as the signature, and the before/after of a weaker model's attempt |

The values in them belong to those projects. Do not copy them into yours; run the workflow and derive a system from your own brand. Notice that the two look nothing alike even though both are developer tools: that is the point.
