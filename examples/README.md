# Examples

`metaflow/system.md` is the design system saved after running the workflow on the metaFlow dashboard
(a React + TypeScript + Vite app). It shows what "Pass 1" produces and what the router reuses on later changes:
direction, tokens, type scale, spacing, component measurements and the defaults that were rejected.

The values in it belong to that project. Do not copy them into yours; run the workflow and let it
derive a system from your brand. Use this file only to see the expected shape of the output.
